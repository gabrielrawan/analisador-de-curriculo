# 🧠 Analisador de Currículo Inteligente

Transforme seu currículo comum em um currículo que chama atenção de recrutadores.

## 📌 Sobre o projeto

O **Analisador de Currículo** é uma aplicação que avalia currículos automaticamente e fornece feedback estratégico baseado em boas práticas de mercado.

A ferramenta analisa estrutura, clareza, palavras-chave e impacto do conteúdo — ajudando candidatos a aumentarem suas chances de contratação.

---

## ⚡ Funcionalidades

- 📄 Upload de currículo (PDF ou texto)
- 🧠 Análise inteligente do conteúdo
- 📊 Feedback detalhado e objetivo
- 🎯 Sugestões práticas de melhoria
- 🔍 Identificação de pontos fracos
- 💼 Otimização para recrutadores e ATS

---

## 🎯 Objetivo

Ajudar candidatos a:

- Passar por filtros automatizados (ATS)
- Melhorar a comunicação profissional
- Destacar habilidades relevantes
- Aumentar taxa de entrevistas

---

## 🛠️ Tecnologias utilizadas

- HTML / CSS / JavaScript
- Integração com IA para análise textual
